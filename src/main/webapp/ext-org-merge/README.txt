Página de fusión de organizaciones externas

- index.html: Interfaz para buscar y seleccionar organizaciones a fusionar.
- ext-org-merge.js: Lógica JS para buscar y llamar al endpoint de fusión del backend.

Uso:
1. Abre index.html en el navegador (con el backend corriendo).
2. Busca organizaciones por nombre.
3. Marca el target (radio) y las fuentes a fusionar (checkboxes).
4. Pulsa "Fusionar seleccionados" para ejecutar la fusión vía API REST.
